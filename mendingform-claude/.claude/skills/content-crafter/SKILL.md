# /content-crafter

Write captions, bios, artist statements, or descriptions for mendingform.

## Input
Tell me:
- What to write: caption / bio / artist statement / listing description
- Context: which piece, platform, or where it will appear

## Output
3 variations, shortest first. Flag if CTA is missing.

## Rules
- Tone: real, grounded, intentional — never salesy
- No hollow adjectives: stunning, amazing, incredible, unique, powerful
- Let the work speak first — meaning before selling
- One clear CTA per caption if needed — never stack asks
- Bio: "I make layered geometric art that lives somewhere between structure and feeling"
  — this is Jackson's approved bio line, use it or build from it
