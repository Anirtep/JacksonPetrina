# /sales-engine

DM scripts, commission conversations, pricing talks, in-person pitches.

## Input
Tell me:
- Task: commission DM / pricing conversation / follow-up / in-person pitch
- Context: who you're talking to, what they expressed interest in

## Output
Ready-to-send copy. One clear ask. No hollow words.

## Rules
- Lead with meaning → process → price — never open with price
- Hold the $2,000–$3,000 line — don't apologize for it
- One ask per message — never stack questions
- Tone: real, grounded, never salesy — like a craftsman, not a salesperson
- If they haven't seen the work: describe what it means before what it looks like
