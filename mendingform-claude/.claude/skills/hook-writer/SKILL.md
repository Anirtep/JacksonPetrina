# /hook-writer

Write the first 3 seconds of a mendingform video.

## Input
Tell me:
- What the video shows (one sentence)
- Platform: TikTok / Reels / Shorts
- Format: text on screen / voiceover / both

## Output
5 hook options, weakest → strongest. No greetings. No hollow adjectives. No emojis unless asked.

## Rules
- Lead with what the material IS before what you made from it
- MDF material tension hooks outperform all others — use when relevant
- Text on screen in first 3s is non-negotiable for performance
- Dark/warm tones and spiritual themes outperform light/mint — reflect that in word choice
- Never start with "I" or "Watch me"
- Weakest option listed first so Jackson can test bottom before promoting top
