# /post-workflow

Full content package for a new mendingform piece. Runs in one call.

## Input
Tell me:
- Piece name
- What it looks like (brief description)
- What it means / the message behind it
- Platform: TikTok / Reels / Shorts / all three

## Output (in this order)

### 1. Hooks — 5 options, weakest → strongest
Lead with material/process. MDF tension hook when relevant.

### 2. Video arc — 3 beats
Opening (0–5s) · Middle (process/build) · End (reveal + one CTA)

### 3. Caption — 3 variations, shortest first
Real, grounded, never salesy. One CTA only.

### 4. Hashtags — 10–15
Label each HIGH / MEDIUM / LOW confidence. Flag 2 anti-patterns to avoid.

## Rules
- Process footage beats finished-piece footage — arc should reflect this
- Text on screen in first 3s is non-negotiable
- Dark/warm/spiritual tone outperforms light/mint — use that in word choice
- Never open with price
- No hollow adjectives anywhere
- One ask, one CTA — never stack them
