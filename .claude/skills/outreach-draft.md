# /outreach-draft — 3 versions of sales or business outreach

When this skill is invoked, ask Jackson for:
1. Who is the target? (person, role, type of business)
2. What is the goal? (reply, meeting, sale, relationship)
3. What context does Jackson have? (mutual connection, prior interaction, cold)
4. Any constraint? (platform: email/DM/LinkedIn, tone, length)

Then return 3 variations:
- **Shortest** (under 5 lines) — most direct
- **Medium** (5-10 lines) — adds one proof point or hook
- **Longer** (10-15 lines) — full context and value prop

Rules:
- No hollow adjectives (amazing, stunning, incredible, unique, powerful, best)
- One clear ask per message — never stack multiple requests
- Never sound salesy — sound like a person
- End each version with a single low-friction call to action
- If Jackson has no existing relationship, lead with value to the recipient, not Jackson's credentials
