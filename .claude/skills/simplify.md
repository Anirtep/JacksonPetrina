# /simplify — Explain any complex topic in plain English

When this skill is invoked, take the topic Jackson provides and return exactly this structure:

1. **One sentence** — plain English summary, no jargon
2. **How it actually works** — the core mechanism, simply
3. **One concrete everyday example** — something real, not abstract
4. **What most people get wrong** about this topic
5. **What to look up next** if Jackson wants to go deeper

Rules:
- Never use jargon without defining it in the same sentence
- If Jackson asks about a technical process (CNC feeds, options Greeks, wood grain, fret placement), explain it as if to a smart person who has never heard the term
- Keep each section to 2-4 sentences maximum
- Do not ask clarifying questions — make your best interpretation and explain it
