# /hook-writer — Write opening hooks for short-form video

The hook is the first 1-3 seconds of a video or the first line of a caption.
On TikTok, Reels, and YouTube Shorts, this is the only thing that matters until the viewer decides to stay.

When this skill is invoked, ask Jackson:
1. What is this video about? (one sentence — what process, what piece, what moment)
2. Platform: TikTok / Instagram Reels / YouTube Shorts (or all three)
3. Format: text on screen, voiceover, or both?

Then return 5 hook options, weakest → strongest:

**Hook formulas that work for process/art/shop content:**
- Mid-process drop — start showing the work with no explanation (curiosity pulls them in)
- "I made this from [one material / one sheet / one block]." (simplicity is surprising)
- "This took [X hours / X layers / X cuts]." (scale creates respect)
- "Most people don't know how this is made." (then show it)
- "Watch what happens at [X seconds]." (tease the best moment)
- "I almost ruined this." (tension, but only use if true)
- Start with the finished piece, then cut to raw material (reverse reveal)

Rules:
- NEVER start with "Hey guys", "Welcome back", or any greeting
- NEVER start with your name or brand name
- The hook must create a reason to keep watching — a question, a tension, a surprise, or a promise
- Shorter is almost always better for the opening line
- Rank your 5 options: option 1 is the safe/obvious one, option 5 is the riskiest/most interesting
- Tell Jackson to test option 1 first to learn, then work toward option 5 over time
