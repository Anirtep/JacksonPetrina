# /content-analyst — Analyze social media performance data

When this skill is invoked, ask Jackson which platform and what data he has available.
Accept: Metricool report, platform CSV export, manual notes, or screenshot of analytics.

Then return:

**What worked (top 3 patterns):**
- Be specific — not "videos with good hooks" but "videos that started mid-process without explanation got 2x the average watch time"
- Label each HIGH / MEDIUM / LOW confidence based on sample size

**What flopped (top 3 patterns):**
- Anti-patterns are as valuable as best practices
- Never skip this section

**Biggest opportunity right now:**
- One specific thing Jackson should do differently in the next 5 posts

**What to test next (5 post plan):**
- Post 1: [specific test]
- Post 2: [specific test]
- Post 3: [specific test]
- Post 4: [specific test]
- Post 5: [specific test]

**Metrics to watch:**
- Watch time / retention rate (most important — tells you if the content held attention)
- Saves (tells you if content is reference-worthy)
- Shares (tells you if content made someone want to show someone else)
- Comments (tells you if content sparked a reaction)
- Followers gained per post (tells you if it brought in new people)
- Reach vs. engagement rate (reach = distribution; engagement = quality)

Rules:
- Never recommend based on vanity metrics alone (likes are the least useful signal)
- Always ask for watch time / retention data if not provided — it's the most important number
- If sample size is small (fewer than 20 posts), say so and adjust confidence accordingly
- Do not invent patterns — only report what the data shows
